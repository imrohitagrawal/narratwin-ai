# ADR 0064: Adversarial Convergence Protocol

- Status: Accepted for Issue #435 implementation review
- Date: 2026-08-21
- Activation: `NONE`
- Authority effect: `NO_AUTHORITY_EFFECT`

## Context

Issue #434 repeatedly reached aggregate green before reviewers found adjacent
validation-order, lifecycle, phase, bound, trust, graph, reconstruction, and
mutation-evidence false passes. Example-driven tests did not prove a closed
invariant family, and late cap pressure encouraged evidence density.

Parent #426 therefore inserts Issue #435 after completed Child B and before
Child C or any later sensitive child. Issue #432 remains separate unmerged
source authority and is not implemented by this decision.

## Decision

Adopt a repository-binding adversarial convergence protocol with:

1. finite declared universes and executable Cartesian-product completeness;
2. the exact bounds-to-phase-verdict pipeline with zero later work after an
   earlier rejection;
3. exact ordered typed findings and exact historical/current verdicts;
4. external independent trust, narrow cryptographic spies, and real public
   vectors;
5. separately enumerated trust and authorization eligibility, with
   graph/conflict participation only after both pass;
6. genuine RED plus three distinct pre-GREEN specialist reviews;
7. an immutable RED-freeze overlay independent of mutable implementation;
8. executed remove/bypass/reorder/replace mutants with named kill tests;
9. separate implementation and evidence blocker classes;
10. 85% risk review and 90% pre-GREEN stop thresholds;
11. focused convergence before full integration confirmation; and
12. top-level quality dispatch under ordinary, policy-only, and merged-main
    Phase 1 Closure modes.

The reference machine matrix is semantic and immutable after RED. A separate
closed overlay created after review freezes its exact RED head, matrix/two-test
blobs, semantic digest, reviewer identities, dispositions, blocker counts, and
nonactivation. The two fixed test blobs are independent oracles that prevent a
coordinated matrix/validator edit from self-approving. Their closed fixture
registry resolves each actual untrusted stimulus and executes it without being
given the expected outcome. A distinct observed transcript and exact
crypto-spy exhaustion prevent an echo oracle, while the freeze binds the actual
ordered RED-node catalog rather than a caller-supplied count. Reconstruction is
required to call the same independently tested complete retained-equality
comparison used by the standalone oracle; the public validator and route gate
must likewise compose the bounded matrix/freeze checks.

`predecessorId` participates in canonical candidate identity. A cyclic
predecessor construction therefore cannot remain identity-valid; it is rejected
at canonical identity before trust, authorization, or graph work. The protocol
does not add a separately mutable or authorization-detached graph-edge identity.

## Rejected alternatives

- More examples without a closed universe: cannot prove completeness.
- Prose-only review checklists: cannot fail CI on semantic drift.
- Matrix and validator as their own oracle: coordinated edits can pass.
- Broad cryptographic mocks: conceal candidate/order/phase errors.
- Graph-first conflict classification: admits ineligible candidates.
- Workflow serialization: hosted jobs are parallel and workflow changes are
  outside this route.
- Adding to the 498-line Stage 8 monolith: would hit its legacy physical cap and
  violate the Issue #435 90% stop rule.
- Dense code or assertions: reduces review discrimination to fit budgets.

## Consequences

Sensitive routes carry more up-front test and review work, but false-pass
classes surface before implementation and full CI. The top-level dispatcher
validates the reference contract on merged main and provides a reusable route
check for later governed matrices. Hosted CI remains parallel; checkpoints and
branch history enforce no-push-before-focused-green.

## Reset rule

A new invariant or false-pass class, semantic/freeze mismatch, cap threshold,
review finding, or scope need stops the route. Preserve exact history, record a
typed OWNER reset before correction, author new RED, renew all three reviews,
and freeze the new identity. Never amend, rebase, drop, rewrite, or force push.
